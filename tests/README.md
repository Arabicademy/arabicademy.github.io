# בדיקות

התיקייה הזו לא משפיעה על האתר. GitHub Pages מגיש רק את index.html,
והקבצים כאן פשוט יושבים בריפו ומחכים.

הם קיימים כדי שאפשר יהיה לשנות את האתר בלי לשבור משהו אחר בשקט.

## מה כל קובץ בודק

**harness.js** — שהקובץ נטען ושהסקריפט שלו רץ עד הסוף. תופס שגיאות תחביר
ודברים שקורסים בטעינה, כלומר התקלות שהופכות את הדף ללבן.

**content.test.js** — סתירות באוצר המילים: כרטיס רבים שנושא את התרגום של
היחיד, קישור שבור, שתי מילים שאי אפשר להבחין ביניהן, אות סופית שנושאת ניקוד.

**practice.test.js** — המנגנונים: המשחקים, המסיחים במשפטים, חלוקת המפגשים,
מודל הידע, ותרגול הבוקר.

**routine.test.js** — הרוטינה היומית. שהגרלת הצהריים יציבה ליום, ושהמשימה
נסגרת רק אחרי שני המשחקים.

## איך מריצים

צריך Node.js. מהתיקייה הראשית של הריפו:

    node tests/run-all.js

או בדיקה בודדת:

    node tests/content.test.js

## מה תקין ומה לא

content.test.js מסמן בקביעות שבעה פריטים, וזה בסדר:

- שתי מילים בלי תשובה שניתן להקליד. אלה בִּ ומִן, שהתרגום שלהן הוא
  "ב..." ו"מ...". הן תמיד יוגשו כשאלה אמריקאית.
- חמש אותיות סופיות עם ניקוד. שם השדה שייכת לאות עצמה ולא מדובר בסמיכות.

כל דבר אחר שנדלק שם הוא כנראה תקלה אמיתית.

## אם משהו נכשל

הפלט אומר מה נשבר ואיפה. אין צורך לתקן מיד, אפשר פשוט להראות אותו.
