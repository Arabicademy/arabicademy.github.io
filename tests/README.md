# בדיקות

התיקייה הזו לא משפיעה על האתר. GitHub Pages מגיש רק את index.html,
והקבצים כאן פשוט יושבים בריפו ומחכים.

הם קיימים כדי שאפשר יהיה לשנות את האתר בלי לשבור משהו אחר בשקט.

## מה כל קובץ בודק

**harness.js** — שהקובץ נטען ושהסקריפט שלו רץ עד הסוף. תופס שגיאות תחביר
ודברים שקורסים בטעינה, כלומר התקלות שהופכות את הדף ללבן.

**content.test.js** — סתירות באוצר המילים: כרטיס רבים שנושא את התרגום של
היחיד, קישור שבור, שתי מילים שאי אפשר להבחין ביניהן, אות סופית שנושאת ניקוד,
וסימון דקדוקי שלא מתאים לתרגום.

**practice.test.js** — המנגנונים: המשחקים, המסיחים במשפטים, חלוקת המפגשים,
מודל הידע, ותרגול הבוקר.

**routine.test.js** — הרוטינה היומית. שהגרלת הצהריים יציבה ליום, ושהמשימה
נסגרת רק אחרי שני המשחקים.

**exam.test.js** — המבחן המלא: שהוא גדל עם הקורס ונעצר בתקרה, ששאלות ההקלדה
תמיד בכיוון שאפשר לענות עליו, ושמה שהמילון מציג זהה למה שהתרגול שולף.

**vowels.test.js** — ניקוד שנחת על האות הלא נכונה, ומילה שהוכנסה פעמיים.

**sweep.test.js** — סבב רחב: שכל מסך שמוצע יש לו מסלול, שאף סשן לא חוזר ריק,
שהמספרים מסכימים זה עם זה, ושכל מחלקת עיצוב ומשתנה צבע באמת בשימוש.

**guide.test.js** — המדריך למשתמש החדש: מתי הוא נפתח, ושהוא לא חוזר למי
שכבר סגר אותו במכשיר אחר.

**reset.test.js** — קביעת סיסמה ראשונה. בעיקר שהמסך לא מסגיר אילו כתובות
רשומות במערכת.

## איך מריצים

צריך Node.js. מהתיקייה הראשית של הריפו:

    node tests/run-all.js

או בדיקה בודדת:

    node tests/content.test.js

## מה תקין ומה לא

חלק מהבדיקות מסמנות פריטים בקביעות, וזה בסדר:

- **שתי מילים בלי תשובה שניתן להקליד** — בִּ ומִן, שהתרגום שלהן "ב..." ו"מ...".
  הן תמיד יוגשו כשאלה אמריקאית.
- **שמונה אותיות סופיות עם ניקוד** — שם השדה שייכת לאות עצמה ולא מדובר בסמיכות.
- **תַאנְיֶה מופיעה פעמיים** — "שנייה (יחידת זמן)" ו"שנייה / אחרת (סדר)".
  שתי מילים שונות שנכתבות אותו דבר.

כל דבר אחר שנדלק הוא כנראה תקלה אמיתית.

## אם משהו נכשל

הפלט אומר מה נשבר ואיפה. אין צורך לתקן מיד, אפשר פשוט להראות אותו.
